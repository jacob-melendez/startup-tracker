The hx-* attributes only upgrade that into a fragment swap of `#results`, with `hx-push-url` keeping the address bar (and therefore the back button and bookmarks) in step with what is on screen. There is deliberately no `cursor` field: changing a filter always restarts at page 1, and a keyset cursor minted under a different filter set would silently return the wrong page. Every `name=` here is part of the pinned query-parameter contract (brief §4.4); an unset control submits nothing, which is what makes "no filters" a plain unfiltered list — the mechanical form of §7.1's rule that classification never excludes. `form_action` is set by the including page (`/` or `/roles`); `is_roles` switches the two places the two views genuinely differ — the sort vocabulary and the closed-roles toggle. -#} {%- set is_roles = form_action == "/roles" -%}

{#- Region comes before City because it is the broader geography and reads as the thing you pick first. It is a filter in this row, not a global scope switch: a switch would need per-user state, which §1 rules out for v1, and would have to be reconciled with every bookmarked URL and keyset cursor. Being a filter, it composes — `metro` and `city` are independent AND predicates, so picking a region does not repopulate the City select and does not need to. The options come from `locations`, not from `config/regions.yaml`, so the form never offers a region that would return nothing (§11). -#}
{#- Grouped by metro because six regions' worth of cities in one flat list is not a control anyone can use (§12 Phase 7). Server-rendered grouping — there is no JavaScript here, as everywhere else in this form. `groupby` sorts as it groups, which the facet's own `ORDER BY metro, city` has already done; it is what guarantees each group is contiguous. The option *value* stays the bare city name, so every URL bookmarked before this phase still means what it meant. The state reaches the label only, and only for a name that occurs more than once: `uq_locations_city_state` makes one row per (city, state), so a repeated name is by definition a name in two states, and the two would otherwise be two identical-looking options. Such an option still filters on the name alone and matches both — Region is how you narrow it. -#}
